# 스칼라 CoreMark 피드백 적용

GitHub의 [피드백 커밋](https://github.com/mhcp0000-jpg/RV23_Dual_ISSUE_OoO/commit/b39f112039d423d249c530a28bac869fbac83f20)이 보고한 IPC 1.2 목표를 O2 스칼라 CoreMark의 `Δminstret / Δmcycle`로 추적한다. 아래 전후 비교는 Windows GCC 15.2로 만든 하나의 2회 ELF를 고정해 실행했다. ELF SHA-256은 `2cf62809926d612583c70528cb4201586ec6694214551919ea1f459d235ab927`다.

| RTL | 2회 cycles | IPC |
| --- | ---: | ---: |
| 응답과 다음 요청을 함께 수락한 기준선 `20bb756` | 675,305 | 0.887857 |
| Bare 물리주소 요청을 I-cache 어댑터에 직결 | 589,377 | 1.017301 |
| 직결 + M-mode 분기 타깃 버퍼 64칸 | 556,261 | 1.077865 |

세 실행 모두 599,574개 명령과 같은 CRC를 기록했다. 이 ELF에서 IPC 1.2의 상한은 499,645사이클이다.

Bare 요청은 수락하는 사이클에 I-cache 어댑터로 넘긴다. 어댑터가 기다리면 요청의 주소, ID, epoch를 잡아 두고 재시도한다. 이전 응답의 PMP 검사 주소는 수락하는 edge까지 보존한다. M-mode에서는 분기 복구 때 타깃 버퍼를 유지하고, 적중한 타깃 블록을 공급하면서 다음 블록 요청을 내보낸다. 권한 전환, FENCE.I, 번역 무효화 및 디버그 정지 때 버퍼를 비운다.

통합 후보는 위 변경에 D-cache 포트 0의 4칸 쓰기 큐, AXI 쓰기 주소·데이터와 B 응답 경로 단축, SRAM 읽기·쓰기 교대 중재를 추가한다. 쓰기 큐에 있는 워드는 읽기를 기다리게 하고, 다른 워드의 resident hit는 허용한다. 스토어 완료는 해당 B 응답을 받은 다음 전달한다.

통합 후보의 H/V, guest Sv39, FENCE.I 148개 패치 사례, 쓰기 큐와 캐시 fault 회귀를 실행했다. 스칼라 성능과 최신 RTL의 Linux 실행은 측정 완료 후 갱신한다.
