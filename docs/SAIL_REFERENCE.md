# Pinned independent Sail reference

The reference uses [Sail RISC-V 0.16](https://github.com/riscv/sail-riscv/tree/e5acebb04ff573e93203596486b831a5974117c3),
commit `e5acebb04ff573e93203596486b831a5974117c3`, generated by the matching
Sail 0.20.3 compiler. The official ISA/model/C-runtime files are unmodified.
The native Windows compiler release archive digest is recorded under
`out/reference/sail_compiler_download.json`.

The initial MinGW build is not accepted as an oracle: the runtime assumes
64-bit `long` and compatible GMP limbs. A separate Cygwin LP64 installation
under `C:/rv_toolchains/cygwin-rv23` passed signed/unsigned 64-bit boundary
roundtrips and 100-bit arithmetic checks. Cygwin documents its LP64 data model
in its [programming guide](https://cygwin.org/cygwin-ug-net/programming.html).
The setup tool verifies signed package metadata and package hashes; the local
installer digest and arguments are retained under `out/reference/cygwin`.
No global PATH, shell profile, desktop shortcut or installation-root registry
entry is added by the setup command.

The upstream network/GDB CLI has host dependency build failures. Instead,
`scripts/reference/sail_bounded_driver.cpp` links the unmodified upstream
`riscv_model` library and supplies ELF loading, bounded stepping, HTIF exit
handling and observation callbacks. It does not implement instruction or trap
semantics. It is named `sail_rv23_reference.exe`, distinct from the upstream CLI.
The host ABI, compiler/runtime DLLs, driver, generated sources, configuration,
ELFs, traces and execution logs are hash-bound by the evidence audits.

The build uses the fixed junction `C:/rv_workspaces/rv23` targeting this project.
This keeps CMake dependencies independent of ephemeral SUBST aliases used by
concurrent RTL regressions. Build scripts verify that junction's resolved target.

`config/reference/sail-rv23.json` selects PA32, eight usable PMP entries in the
base 16-entry CSR group, four HPM counters, Sv39/Sv39x4, VLEN128/ELEN64,
PMLEN 0/7, 64-byte cache/reservation granules, Svade and the required profile
extensions. Unsupported optional instruction extensions are disabled. PLIC,
HostIF device behavior, cycle/time equality and implementation-specific HPM
event selection are outside this comparison's scope.

Reproduction commands from the project root:

```text
python scripts/setup_reference_cygwin.py
python scripts/check_sail_host_abi.py
python scripts/build_sail_reference.py
python scripts/prepare_sail_config.py --validate
python scripts/run_sail_upstream_comparison.py --resume
python scripts/run_sail_retirement_negative.py
python scripts/audit_sail_comparison.py
```

The upstream test bodies, macros and physical environment are unchanged.
The shared linker places `tohost` at the RTL HTIF polling address. Each ELF
is used without alteration by both models. All 168 common functional ELFs
passed both; the 152 user ISA programs additionally matched 61,754 retirement
records exactly: PC, raw instruction, trap/cause and scalar integer/FP
destination/value. The native boot sequence and asynchronous HTIF completion
tail are excluded. The 16 M/S tests have passing embedded self-checks on both
models; their complete timing-sensitive traces are not asserted equivalent.
A copied real trace with bit 40 of a writeback corrupted was rejected by the
actual differential audit, with the original trace preserved.

Evidence is `out/rva23/sail_reference_evidence.json`,
`out/rva23/sail_upstream_comparison/report.json` and
`out/rva23/sail_upstream_comparison/retirement_audit.json`. This is finite
independent architectural evidence. It does not establish full ACT4/profile
certification, vector-state differential coverage, exhaustive memory ordering
or timing/synthesis sign-off. The pinned ACT4 4.1.0 source is retained for the
remaining certification work; the current driver is not advertised as its
complete reference CLI.

The 2026-11-11 privileged follow-up uses a separate observation driver at
`out/reference/sail-event-driver` linked against the same unmodified Sail
libraries. `scripts/reference/sail_trace_events.h` records WFI when entering
wait and interrupt traps before fetch, which the original callback omitted.
The original driver, 168 ELF results and all original traces remain preserved.
The new comparison passed all 16 M/S ELF prefixes, 2,554 events, matching PC,
raw instruction, trap/cause and full scalar writeback without masking CSR
values. Interrupt presence is explicitly recorded in the new Sail CSV; the
RTL CSV represents the trap cause separately from the interrupt bit. This is
event/value comparison, not cycle or complete privileged-state equivalence.

Run `python scripts/build_sail_event_driver.py`, then
`python scripts/run_sail_event_comparison.py` and
`python scripts/audit_sail_event_comparison.py`. The audit rechecks source,
model-library, compiler/runtime, ELF, trace and log hashes, all 16 case names,
and two controls that remove an interrupt or WFI row from copied traces.
Both controls are rejected at the omitted event. Reports and the current
audit are in `out/rva23/sail_privileged_events`.

The separate vector-state follow-up is `scripts/run_vector_state_differential.py`.
It uses the same Sail event driver and full H/V RTL with one identical ELF per
legal SEW/LMUL combination (22 for VLEN128/ELEN64). Five checkpoints per ELF
whole-store all 32 V registers; scalar LDs expose every bit to exact comparison.
All 7,040 vector words, 770 vector CSR values and 38,918 trace events matched.
The selected operations exercise undisturbed tails/masks, vstart=1, shortened
and zero VL, saturation and gather. The source and original traces are preserved
when a copied snapshot word's highest bit is flipped; the comparison rejects it.
Recheck with `python scripts/audit_vector_state_differential.py`; evidence is
under `out/rva23/vector_state_differential`. This adds a defined integer-state
subset; FP, agnostic-choice and guest fault/restart differential coverage remain
separate from these passing snapshots.

`scripts/run_vector_agnostic_differential.py` adds the remaining three VTA/VMA
policies to the same 22 fixture types. The current Sail and RTL values matched
over 66 cases and 21,120 more vector words. The per-element oracle accepts
permitted agnostic choices while checking the exact active results and required
preservation. The auditor confirms five policy-only VSETVLI changes per loaded
ELF payload, accepts two legal-choice controls, and rejects four corrupt state
controls. Recheck with `python scripts/audit_vector_agnostic_differential.py`.
