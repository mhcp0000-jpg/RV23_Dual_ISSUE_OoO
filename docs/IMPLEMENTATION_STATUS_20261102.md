# 2026-11-02 privileged implementation checkpoint

The target remains the complete official RVA23S64 profile. This revision fixes
eight concrete architectural omissions found through the normative audit and
independent upstream execution:

- VU SFENCE.W.INVAL/SFENCE.INVAL.IR now raise virtual instruction, cause 22.
- U WFI with S-mode implemented traps within a bounded time (immediately).
  VU and machine TW interception keep their specified exception priorities.
- The mandatory mconfigptr CSR returns zero in M-mode. Writes and all
  lower-privilege accesses still raise illegal instruction.
- M/S/H FIOM fields are writable. Existing conservative fences and atomic
  serialization already order all memory classes, including FIOM expansions.
- mip.SEIP reads the OR of software and external pending state, while
  CSRRS/CSRRC modify only its software-owned state.
- Non-delegated SEI/SSI/STI delivered to M preserve causes 9/1/5 and the
  architectural priority order. The missing selection previously produced
  cause 0 in the upstream vectored-interrupt test.
- Guest EBREAK/C.EBREAK now set GVA when writing a guest PC to tval. The
  address-trap classification also includes instruction-address misalignment.
- The base 16-entry PMP CSR group now exposes the eight unused entries as
  WARL zero with ignored writes, retaining eight usable protection comparators.

All 69 implemented-feature steps passed against the current RTL. The renewed
RV32 release passed all six gates: 58 block/backend cases, 22 ELF programs,
boot/cache/seeded memory checks, negative controls, exact-ELF performance and
retirement-control comparisons.

The committed CSR test passed 1,971 checks, including 320 intercept contexts,
960 SRET/SFENCE/WFI permission checks, FIOM/SEIP ownership and all 127 nonempty
M-target physical interrupt combinations. The native privilege matrix passed
390 cases and 642 precise traps.
The breakpoint metadata matrix passed 33 forms/delegation contexts and 66
precise traps, covering M/HS/VS/U/VU, GVA/MPV/SPV/SPVP and illegal-instruction
clearing. A further native ELF passed eight MPRV+MPV explicit/implicit-PTE
guest faults and two ordinary-M controls, checking mtval2/mtinst and actual
M-mode trap authority despite delegated guest-fault causes.

Independent upstream tests passed 152 RV64 user-level programs and 16 reviewed
M/S programs on the same H/V-enabled SoC. Twenty-five previously checked scalar
profile ELFs were then replayed on that same executable without rebuilding
them, including all 5,261 embedded scalar FP oracle cases. Host packets and
precise fault locations/values matched the original executions.

Native vector tests again passed 733 integer, 235 FP and 8,660 Bare-memory
packets, plus S/VS state, Sv39 and guest partial-fault restart. Six H/HPM ELFs
passed two-stage translation, interrupts, HLV/HSV/HLVX, pointer masking and
overflow tests. Directed scalar/vector latency checks passed, and the injected
data-dependent VCLZ early-exit control was rejected.

The preserved original TIM ELF remains unchanged and was executed again:
576,450 timed instructions, 513,076 cycles, IPC 1.12351776 on the cached RV32
SoC. The saved cache A/B ELFs remain unchanged too: Iter 2 IPC 1.09744171 and
Iter 10 IPC 1.10647963. These are legacy RV32 measurements, not RV64/H IPC or
an official CoreMark score. I/D caches remain 32 KiB each, with two 64-bit
banks, AXI64 and shared 1 MiB SRAM.

All 58 mandatory extension names are mapped to compiled implementation paths
and check drivers in `config/rva23_implementation_map.json`. This establishes
traceability and finite functional evidence, not complete normative coverage.
Full ACT4/Sail architectural validation, finer clause coverage and broader
memory-ordering/timing proof remain open. No synthesis/STA or complete profile
certification is claimed. Native debug ports are connected; standard external
Debug Module/JTAG remains separate platform work.
The pinned official Sail 0.16 model, generated by Sail 0.20.3 and compiled
with the validated Cygwin LP64/GMP ABI, now runs through a separate bounded
ELF/HTIF host driver. The ISA, model and C runtime remain unmodified. The
upstream network/GDB CLI is not part of this local driver.

All 168 common functional ELFs passed both Sail and the current H/V RTL. For
all 152 user ISA ELFs, 61,754 retirement records matched exactly: PC, raw
instruction, trap/cause and scalar integer/FP destination/value. Boot ROM and
asynchronous HTIF completion tails are excluded; no cycle equality or M/S
trace-equivalence claim is made. A copied real trace with writeback bit 40
corrupted was rejected by the actual audit. The reference config uses PA32,
16 PMP CSR entries/eight usable entries, four HPM counters, Sv39/Sv39x4,
VLEN128/ELEN64 and PMLEN 0/7. This remains a finite differential suite, not full
ACT4/profile certification or a vector-state differential proof.
